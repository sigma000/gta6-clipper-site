Privacy Policy

Last updated: 18 November 2026

GTA6 Clipper ("the app") is a personal publishing tool. It is used only by its operator to upload videos to the operator's own social media accounts.

Data the app accesses

  • Platform authorization tokens (YouTube, TikTok, Instagram, X, Twitch) for the operator's own accounts, used only to upload videos, read basic account info, and create Twitch clips.
  • Public clip information from Twitch (clip title, view count, streamer name) used to choose and credit clips.
  • Public chat message counts in approved streamers' Twitch chats, used only to detect exciting moments. Message contents are not stored.

How data is stored

Tokens and a list of posted clips are stored locally on the operator's computer. Nothing is sold, shared with third parties, or used for advertising.

Other users

The app does not offer accounts to the public and does not collect personal data from viewers or other users.

Deleting data

The operator can revoke the app's access at any time from each platform's connected-apps settings, which makes the stored tokens useless, and can delete the local files.

Contact

Questions about this policy: open an issue on this site's GitHub repository.
